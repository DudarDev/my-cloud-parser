# 🚀 Swappa Pro Cloud Parser (v6.0)

**Swappa Pro Cloud Parser** — це потужний, гнучкий та професійний інструмент на Python для автоматизованого збору даних, моніторингу цін та аналізу ринку б/у електроніки з веб-сайту [Swappa.com](https://swappa.com).

Версія **6.0 Pro** повністю перероблена: додано об'єктно-орієнтовану архітектуру, розумний аналітичний дашборд, локальний оффлайн-режим, підтримку файлів конфігурації `.env`, стилізовані звіти Excel і Word, а також трекінг динаміки зміни цін у SQLite.

---

## ✨ Основні можливості

- **🌐 Гібридний режим роботи**:
  - **ScrapingBee API**: обхід Cloudflare та захисту від ботів з рендерингом JavaScript.
  - **Direct HTTP**: прямі запити з маскуванням під реальний браузер (User-Agent, Sec-Ch-Ua).
  - **Offline Local HTML (`--html_file`)**: парсинг збережених HTML-сторінок без звернення до мережі (ідеально для тестів та зневадження).
- **📊 Інтерактивний Rich-дашборд**:
  - Розрахунок медіанної, мінімальної, максимальної та середньої ціни.
  - Аналітика зносу акумуляторів (відсоток батарей нижче 80%).
  - Топ-5 найвигідніших пропозицій (алгоритм `deal_score` від 1 до 100).
- **💾 Розумна база даних SQLite з трекером цін**:
  - Дедуплікація за унікальним кодом оголошення (`code UNIQUE`).
  - Автоматична фіксація **історії зміни цін**: якщо продавець знизив або підвищив ціну, зміна записується в окрему таблицю `price_history`.
  - Перегляд динаміки цін однією командою: `python main.py --history`.
- **📑 Багатоформатний експорт Pro**:
  - **XLSX (Microsoft Excel)**: 2 вкладки («Объявления» зі стилізованою шапкою та авто-шириною колонок + «Аналитика» зі зведеними показниками).
  - **DOCX (Microsoft Word)**: зведений звіт з таблицею метрик та картками оголошень.
  - **CSV**: табличні дані в кодуванні `utf-8-sig`.
  - **JSON**: деталізований вивід разом з метаданими та аналітикою.
- **🧪 Покриття автотестами**:
  - Набір тестів `pytest` для перевірки парсингу, нормалізації даних, бази даних та експортерів.

## 📁 Структура проєкту

```
my-cloud-parser/
│
├── main.py                     # Головна точка швидкого запуску
├── requirements.txt            # Усі залежності проєкту
├── pytest.ini                  # Конфігурація для запуску pytest
├── .env.example                # Шаблон змінних оточення
├── sample_swappa.html          # Тестовий HTML-файл для перевірки
│
├── my_cloudparser/             # Основний пакет бібліотеки
│   ├── __init__.py             # Публічний API пакету
│   ├── __main__.py             # CLI точка входу (аргументи командного рядка)
│   ├── scraper.py              # Клас SwappaScraper та нормалізація даних
│   ├── database.py             # SQLite ORM, дедуплікація та price_history
│   ├── analytics.py            # Розрахунок аналітики та Rich-термінал
│   └── exporters.py            # Експорт у CSV, XLSX, JSON, DOCX
│
└── tests/
    └── test_parser.py          # Автоматизовані тести pytest
```

## 🛠️ Встановлення та налаштування

### 1. Створення віртуального оточення

```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 3. Налаштування API ключа (необов'язково, але рекомендовано)

Створіть файл `.env` у корені проєкту (скопіювавши `.env.example`):

```bash
cp .env.example .env
```

Вкажіть ваш ключ у файлі `.env`:
```env
SCRAPINGBEE_API_KEY=ваш_ключ_від_scrapingbee
```
*(Якщо ключа немає, скрипт може працювати через `--direct` або оффлайн через `--html_file`).*

## ▶️ Приклади використання

### 1. Базовий запуск (через ScrapingBee або .env)

```bash
python main.py
```

### 2. Запуск з явним передаванням ключа та іншого товару

```bash
python main.py --api_key "ВАШ_КЛЮЧ" --url "https://swappa.com/listings/samsung-galaxy-s22-ultra" --save_db
```

### 3. Оффлайн-тест на локальному HTML без витрати інтернет-трафіку

```bash
python main.py --html_file sample_swappa.html --save_db --output my_report
```

### 4. Прямий HTTP-запит без ScrapingBee

```bash
python main.py --direct --url "https://swappa.com/listings/apple-iphone-13-pro-max"
```

### 5. Перегляд історії зміни цін у базі даних

```bash
python main.py --history
```

### 6. Вибірковий експорт тільки в Excel та CSV

```bash
python main.py --formats xlsx csv --output my_pricing
```

## 🧪 Запуск тестів

Для запуску повного набору тестів виконайте:

```bash
python -m pytest -v
```

Усі 6 тестів перевіряють:
1. `test_data_cleaning_helpers` — нормалізацію цін, відсотків батарей та об'єму пам'яті.
2. `test_html_parsing_and_scoring` — розбір колонок та розрахунок індексу вигоди `deal_score`.
3. `test_statistics_calculation` — аналітику, розподіл та медіани.
4. `test_database_and_price_history` — дедуплікацію та фіксацію динаміки зміни цін.
5. `test_exporters` — генерацію всіх 4 форматів файлів.
6. `test_offline_file_mode` — роботу з локальними файлами сторінок.
